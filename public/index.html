02

04

Estructuras especiales

Pasarelas, soportes de tuberías y estructuras para proyectos de energía, sujetas a evaluación técnica.

El sistema completo.
El alcance que necesita.

Solo estructura, estructura con cubierta o una solución que incorpore cerramientos y complementos. Definimos qué incluye cada propuesta para facilitar la planificación del proyecto.

Para alcance llave en mano, la obra civil, el montaje y las instalaciones se detallan expresamente en la propuesta.

  1. Solo estructuraColumnas, vigas, pórticos, cerchas, correas y arriostramientos.
  2. Estructura + cubiertaAñade la cubierta y sus terminaciones.
  3. Estructura + cubierta + cerramientosIncorpora cerramientos y aislamiento.
  4. Nave completaEnvolvente y complementos: escaleras, plataformas y accesos según diseño.

Cada aplicación se desarrolla según las cargas y el alcance definidos para el suministro.
